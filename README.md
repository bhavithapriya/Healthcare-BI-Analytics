# Healthcare BI Analytics Dashboard

An interactive healthcare data analytics project developed using Microsoft Power BI to explore patient demographics, clinical indicators, laboratory results, medication adherence, and healthcare risk patterns.

## Project Overview

This project transforms healthcare datasets into an interactive dashboard to support data-driven healthcare analysis and clinical performance monitoring.

The dashboard provides insights into patient health indicators, disease-related trends, laboratory abnormalities, medication efficacy, and high-risk patient populations.

## Dashboard Pages

The Power BI report contains eight analytical pages:

1. **Executive Summary** – Overall healthcare KPIs and performance overview.
2. **Diabetes Intelligence** – HbA1c analysis and diabetes-related indicators.
3. **Kidney Function – CKD** – eGFR analysis and chronic kidney disease indicators.
4. **Cardiovascular Risk** – LDL levels and cardiovascular risk indicators.
5. **Lab Trend Analysis** – Laboratory testing volume and abnormality trends.
6. **Medication Efficacy** – Medication adherence and treatment-related analysis.
7. **High-Risk Patients** – Identification and analysis of high-risk patient groups.
8. **Patient Profile** – Patient-level demographic and clinical information.

## Technology Stack

## Dataset

The project uses healthcare datasets obtained from Kaggle, covering:

* Patient demographics
* Diagnoses
* Laboratory results
* Medication records
* Patient outcomes

Raw CSV datasets are excluded from this repository. Their redistribution permissions and suitability must be verified with the original dataset sources.

## How to Use

1. Clone or download this repository.
2. Open `powerBI/Healthcare_Dashboard.pbix` using Microsoft Power BI Desktop.
3. If you want to refresh the report, obtain the original datasets from their respective sources.
4. Update the data source paths in Power BI if required.
5. Refresh the data and explore the dashboard pages.
